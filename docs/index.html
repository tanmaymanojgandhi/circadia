Circadia

OKLCH themes for code, terminals, and documents.

Circadia provides OKLCH color themes for editors, terminals, and documents. Automated checks validate text contrast on three base backgrounds in all four palettes. Rendered application states and color vision accessibility need separate validation.

Color vision accessibility

Color and typography provide different cues; CVD validation remains pending.

📏

1. Lightness, chroma, and hue

OKLCH describes lightness, chroma, and hue. Syntax roles use different colors, but those differences need evaluation under CVD simulations.

Minimum lightness separation is not currently enforced.
🔤

2. Typographic cues

Some editor ports use bold keywords and italic comments to supplement syntax color. Coverage varies between applications.

Support depends on the application, font, and syntax scope.
🛡️

3. Diagnostic colors

Diagnostic colors mark errors and conflicts. Color alone should not be the only way to identify these states.

Diagnostic indicators should supplement color with symbols or text.

Contrast validation

Text in all four palettes is checked against three base backgrounds.
