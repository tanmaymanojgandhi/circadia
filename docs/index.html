Circadia

Perceptually uniform, low-strain themes engineered for continuous focus.

Circadia is an open color specification and multi-platform theme system engineered in OKLCH for cross-platform editors, terminal emulators, and document renderers. Built around human ocular biophysics, circadian light cycles, and strict mathematical accessibility, Circadia delivers 100% Strict WCAG 2.1 AAA contrast (≥ 7.0:1) across all UI and syntax tokens with multi-dimensional Color Vision Deficiency (CVD) support.

Multi-Dimensional CVD Separation (Color Vision Deficiency)

Ensuring full usability for Deuteranopia (green-blind), Protanopia (red-blind), and Monochromacy.

📏

1. OKLCH Luminance Steps (ΔL ≥ 8%)

Instead of relying on fragile hue differences that collapse under CVD, conflicting syntax pairs (e.g. strings vs types vs keywords) are engineered with a guaranteed perceptual lightness delta (ΔL ≥ 8.0%).

Tokens remain instantly distinguishable even in total greyscale or high-contrast monochromacy.
🔤

2. Dual-Channel Typographic Encoding

Keywords and control-flow syntax are systematically rendered with bold font weights across all 19 ports, creating an immediate non-chromatic visual channel for code comprehension.

Zero ambiguity regardless of monitor calibration or color blindness tier.
🛡️

3. Quarantined Destructive Red

Saturated alarm red is strictly quarantined for syntax errors, merge conflicts, and linter warnings. Routine syntax never uses red, preventing cognitive alarm fatigue and color confusion.

Alert signals remain authoritative and impossible to overlook.
