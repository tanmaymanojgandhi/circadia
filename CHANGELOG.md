# Changelog

## 2.1.0

- Dark variants share neutral text, an ordered neutral heading ladder, and vibrant semantic syntax colors. Their existing backgrounds remain unchanged.
- Obsidian uses blue links and sage controls across all dark variants. Editor and terminal accents remain specific to each variant.
- All four palettes enforce 7:1 text contrast on canvas, surface, and element backgrounds. Generated VS Code selection and search states have regression checks.
- Updated supported ports and added generation for previously hand-maintained consumers.
- Public descriptions state measured contrast coverage and remaining CVD and rendered-state validation work.
